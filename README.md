# MLB Home Run Leaders Dashboard

An interactive dashboard built with **Streamlit** that analyzes historical **home run leaders** in Major League Baseball (MLB). The data was scraped using **Selenium**, cleaned with **Pandas**, stored in **SQLite**, and visualized with Streamlit and **Altair**.

---

## 📌 Features

- View top home run leaders by year, league, or all-time
- Interactive filters: league, year, HR threshold
- Visualizations:
  - HRs by player (bar chart)
  - Average HRs over time (line chart)
  - HR distribution (histogram)
  - Top teams by total HRs
  - Top 10 all-time HR leaders (with dynamic mode switching)

---


## Steps to run: 

- 1. Clone repo
- 2. Create a virtual environment
- 3. Install dependencies ( pip install -r requirements.txt ) 
- 4. Run the dashboard ( streamlit run app/dashboard/dashboard.py )
